**Smart Library** — интеллектуальный Telegram-бот, спроектированный по стандартам Production-Ready архитектуры. Бот функционирует как персональная онлайн-библиотека с поиском книг, университетских и школьных учебников, научной и художественной литературы практически на любую тему.

Бот работает **исключительно через Telegram Webhook** (без Long Polling) на базе высокопроизводительного асинхронного стека: **FastAPI + aiogram 3.x + PostgreSQL (Asyncpg) + SQLAlchemy 2.0 + Redis**.

| Кнопка | Описание |
|---|---|
| **📚 Найти книгу** | Полнотекстовый поиск по названию, автору или ключевым словам |

### 2. 🔍 Интеллектуальный поиск книг
При нажатии на кнопку **«📚 Найти книгу»** бот выводит интерактивное окно с подсказками и inline-кнопками выбора режима поиска:
- **📖 По названию** (`intitle:`): точный поиск конкретного произведения (например: *Война и мир*, *Clean Code*).
- **✍️ По автору** (`inauthor:`): поиск всех произведений конкретного автора (например: *Федор Достоевский*, *Стивен Кинг*, *Роберт Мартин*).
- **🏷️ По ключевым словам**: поиск по широкой тематике или терминам (например: *Квантовая физика*, *Машинное обучение*, *История Рима*).
- **🔢 По ISBN**: мгновенный поиск по международному стандартному номеру книги.
- **💬 Прямой ввод**: пользователь может отправить любой поисковый запрос текстовым сообщением в чат.

- 📖 **Название книги** (с оригинальным названием при наличии)

- 📅 **Год выпуска**
- 🌐 **Язык издания**
- 🏢 **Издательство**

- 📑 **Доступные форматы** (PDF, EPUB, TXT)

- 🏛️ **Источник данных** (Google Books, Open Library)

#### Интерактивные кнопки под карточкой:
- **🌐 Читать онлайн (Легальный источник)**: прямая ссылка на веб-ридер Google Books или Open Library.
- **🛒 Купить / Читать легально**: ссылка на официальный магазин Google Play Books или партнерские сервисы.
- **📥 Скачать PDF / EPUB**: мгновенная отправка документа в Telegram (если произведение распространяется свободно).
- **⭐ В избранное / ❌ Удалить из избранного**: сохранение книги в личный список.
- **⬅️ Назад к результатам**: удобный возврат к постраничной выдаче.

## 🚀 Быстрый запуск

### Шаг 1. Клонирование и настройка окружения

1. Перейдите в каталог проекта:
   ```bash
   cd smart-library-bot
   ```

2. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```

3. Заполните переменные в `.env`:
   ```ini
   # Токен вашего бота от @BotFather
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

   # Публичный HTTPS URL сервера для Webhook
   WEBHOOK_URL=https://smartlibrary.yourdomain.com
   WEBHOOK_PATH=/webhook
   WEBHOOK_SECRET=your_super_secret_webhook_token_e9402ab84

   # База данных PostgreSQL (для Docker Compose)
   DATABASE_URL=postgresql+asyncpg://postgres:postgres@postgres:5432/booklibrary

   # Кэш Redis
   REDIS_URL=redis://redis:6379/0

   # Telegram ID администраторов (через запятую)
   ADMIN_IDS=123456789

   # Ключ Google Books API (опционально)
   GOOGLE_BOOKS_API_KEY=
   ```

---

### Шаг 2. Запуск через Docker Compose (Рекомендуемый способ)

Для старта всех трех сервисов (**FastAPI Webhook Bot**, **PostgreSQL 16**, **Redis 7**) выполните:

```bash
docker-compose up --build -d
```

Проверить статус работы сервисов:
```bash
docker-compose ps
```

Проверить логи бота:
```bash
docker-compose logs -f bot_api
```

При запуске бот:
1. Автоматически применит структуру базы данных и выполнит начальный сидинг категорий и дисциплин.
2. Проверит соединение с Redis.
3. Зарегистрирует Webhook в Telegram Bot API с секретным токеном безопасности.
4. Будет готов к обработке входящих обновлений.

---

### Шаг 3. Локальный запуск для разработки

1. Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # На Linux / macOS
   # или .venv\Scripts\activate  # На Windows
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите туннель для тестирования Webhook (например, ngrok):
   ```bash
   ngrok http 8000
   ```
   Скопируйте выданный `https://xxxx.ngrok-free.app` в переменную `WEBHOOK_URL` в `.env`.

4. Запустите сервер:
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```

## ⚖️ Лицензия и соблюдение авторских прав

Бот разработан строго в соответствии с принципами открытого доступа и авторского права:
- Все книги сопровождаются ссылками на официальные страницы (Google Books Preview, Open Library, Internet Archive).
- Скачивание файлов активируется только для изданий с открытыми лицензиями (Public Domain, Creative Commons).
- Для коммерческих изданий предоставляются ссылки на легальное чтение и приобретение у правообладателей.
